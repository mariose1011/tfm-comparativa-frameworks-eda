# Online Retail — diccionario de datos

Fuente: UCI Machine Learning Repository  
Página: https://archive.ics.uci.edu/dataset/352/online+retail  
DOI: `10.24432/C5BW33`

El archivo contiene las líneas de las transacciones realizadas entre el 1 de diciembre de 2010 y el 9 de diciembre de 2011 por una empresa británica de comercio electrónico sin tienda física. La empresa comercializa principalmente artículos de regalo y parte de sus clientes son mayoristas.

Cada fila representa una línea de factura, no necesariamente una factura o compra completa.

## Variables

| Variable | Descripción |
| --- | --- |
| `InvoiceNo` | Número de factura. Es un identificador nominal. Cuando comienza por `C`, UCI indica que se trata de una cancelación. |
| `StockCode` | Código nominal asignado al artículo o concepto facturado. |
| `Description` | Descripción del artículo o concepto. |
| `Quantity` | Cantidad registrada en la línea de factura. |
| `InvoiceDate` | Fecha y hora de la transacción. |
| `UnitPrice` | Precio por unidad expresado en libras esterlinas. |
| `CustomerID` | Identificador nominal del cliente. |
| `Country` | País asociado al cliente. |

Este documento proporciona únicamente el significado publicado de los campos. No contiene valores esperados, resultados de referencia ni reglas de corrección.
