# Evaluaciones de calidad del TFM

Esta carpeta reúne las puntuaciones y evidencias de la evaluación de calidad de las dieciocho ejecuciones definitivas, incluidas las dos parciales. La evaluación se completó el 6 de octubre de 2026.

El [Excel](Evaluacion_calidad.xlsx) recoge las propuestas iniciales, las puntuaciones finales y sus justificaciones. La evaluación cuenta con un único evaluador humano con asistencia de IA.

Criterios: [protocolo](01_protocolo_calidad_Q1_Q10_v0.1.md), [guía D1](02_ficha_D1_bike_sharing.md) y [guía D2](02_ficha_D2_online_retail.md).

## Contenido y archivos relacionados
- `Evaluacion_calidad.xlsx`: puntuaciones y justificaciones de las dieciocho ejecuciones.
- Protocolo y guías de D1 y D2: criterios comunes y comprobaciones específicas de cada dataset.
- `fichas/`: dieciocho fichas _desglose.md y dieciocho archivos _comprobaciones.json con los cálculos y evidencias de la evaluación.
- `outputs/experimento/`: archivos y trazas originales de las ejecuciones.
- `datasets/experiment_inputs/`: datos y documentación pública proporcionados a los agentes.
- `datasets/reference_private/`: valores y criterios de referencia utilizados para evaluar los resultados, separados de las entradas accesibles a los agentes.

Para consultar conjuntamente estos materiales deben conservarse las rutas relativas entre las carpetas. Las copias de seguridad, las propuestas anteriores y los archivos temporales quedan fuera del paquete principal de entrega.
